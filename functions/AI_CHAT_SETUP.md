# تفعيل ردّ الذكاء الاصطناعي في شات ADAM

الشات نفسه (بين العميل ومدربه) شغال دلوقتي من غير أي إعداد إضافي. الخطوات
دي مطلوبة بس عشان تفعّل الرد التلقائي من الذكاء الاصطناعي (OpenAI) على
رسايل العميل. لغاية ما تعمل الخطوات دي، الشات هيفضل شغال عادي كمحادثة
بينك وبين عميلك، وأي وقت تخلص الإعداد الرد الذكي هيبدأ يشتغل من غير ما
تحتاج أي تعديل تاني في الكود.

الإعداد ده مرة واحدة بس، ومحتاج شوية خطوات تقنية — لو حبيت اعمله في جلسة
معايا خطوة خطوة، قولي وهساعدك فيها أول بأول.

---

## 1) رفّع مشروع Firebase بتاعك لخطة Blaze

خطة Firebase المجانية (Spark) مش بتسمح للوظائف السحابية (Cloud Functions)
إنها تكلم خدمة خارجية زي OpenAI. لازم تتحول لخطة **Blaze** (مدفوعة على
حسب الاستخدام — يعني بتدفع بس على اللي بتستخدمه فعلاً، ومعظم الاستخدام
هنا هيبقى تكلفته قليلة جدًا).

- روح على [Firebase Console](https://console.firebase.google.com) → اختار مشروعك
- من الإعدادات (الترس ⚙️) → **Usage and billing**
- دوس **Modify plan** واختار **Blaze**
- هتحتاج تربط وسيلة دفع (بطاقة) — ده إجراء من Google نفسها جوه صفحتهم،
  متحطش أي بيانات بطاقة في أي حتة تانية

## 2) اعمل حساب OpenAI واحصل على مفتاح API

- روح على [platform.openai.com](https://platform.openai.com) واعمل حساب
- من **Settings → Billing** حط وسيلة دفع (OpenAI برضو بتحسب على حسب
  الاستخدام — استخدام شات زي ده بالموديل المقترح `gpt-4o-mini` تكلفته
  بسيطة جدًا للرسالة الواحدة)
- من **API keys** اعمل مفتاح جديد وانسخه فورًا (مش هتقدر تشوفه تاني بعد
  ما تقفل الصفحة)
- **مهم:** المفتاح ده متبعتوش لأي حد ولا تحطه في أي شات أو إيميل — هنحطه
  في مكان آمن جوه Firebase في الخطوة الجاية بس

## 3) ثبّت أدوات سطر الأوامر (لو أول مرة)

على جهازك (Mac/Windows):

```bash
npm install -g firebase-tools
firebase login
```

هيفتحلك المتصفح تسجل دخول بحساب Google بتاع مشروعك.

## 4) جهّز مجلد الوظائف (functions)

جوه مجلد مشروعك (نفس المكان اللي فيه index.html و app.js)، شغّل:

```bash
firebase init functions
```

- اختار **Use an existing project** وحدد مشروعك
- اختار **JavaScript**
- لو سألك "overwrite index.js?" أو "package.json?" قول **لأ** لحد ما تحط
  الملفين اللي بعتهملك (`functions/index.js` و `functions/package.json`)
  مكان اللي اتعملوا تلقائيًا

بعد كده حط ملفاتي (`functions/index.js` و `functions/package.json`) مكان
اللي اتولّدوا، وشغّل جوه مجلد `functions`:

```bash
cd functions
npm install
cd ..
```

## 5) حط مفتاح OpenAI بأمان

```bash
firebase functions:secrets:set OPENAI_API_KEY
```

هيطلب منك تلصق المفتاح — الصقه واضغط Enter. المفتاح هيتخزن مشفّر جوه
Firebase نفسها، مش في أي ملف من ملفاتك.

## 6) انشر الوظيفة

```bash
firebase deploy --only functions
```

لو خلصت من غير أخطاء، الرد التلقائي هيبدأ يشتغل فورًا — ابعت رسالة من
حساب عميل تجريبي وشوف الرد بيظهر بعد ثواني قليلة.

---

## ملاحظات مهمة

- الرد الذكي بيرد بس على رسايل العميل — لو انت رديت كمدرب، مش هيدخل يرد
  تاني على نفس الرسالة.
- الموديل متظبط يحوّل أي سؤال طبي أو خاص بالفلوس/الاشتراك لمدربك بدل ما
  يجاوب عليه هو، حسب التعليمات اللي في أول الملف (`SYSTEM_PROMPT`) — لو
  حبيت تغيّر أسلوبه أو تضيف تعليمات تانية، عدّل النص ده وانشر تاني بنفس
  أمر الخطوة 6.
- كل رسالة العميل بتبعتها بتكلّفك جزء صغير من السنت على حساب OpenAI —
  تقدر تحط حد أقصى شهري (budget) من صفحة Billing بتاعتهم عشان تطمن.
- لو حصل أي مشكلة (المفتاح غلط، أو تعدّى الحد المسموح)، الشات العادي
  (بينك وبين عميلك) هيفضل شغال عادي زي ما هو، الرد الذكي بس هو اللي مش
  هيظهر.
