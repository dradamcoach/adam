## 2. Exercise/rehab content sources
- free-exercise-db (yuhonas): github.com/yuhonas/free-exercise-db and LICENSE.md. Unlicense (public domain dedication, "sell or distribute for any purpose"). 800+ exercises JSON with JPG images. README credits Ollie Jennings for the original dataset; image provenance is NOT stated -> the Unlicense covers what the repo author owns, but the origin of the images is unverified. Medical/rehab accuracy not vetted. Risk: low copyright-licence risk for JSON, medium for images.
- wger: github.com/wger-project/wger README and wger.readthedocs.io. Code AGPL-3.0-or-later; docs CC-BY-SA-4.0; "Exercise/Ingredient Data: Creative Commons (see individual entries)". Docs page states initial exercise/ingredient data under CC-BY-SA 3.0, and "Some images were taken from Wikipedia" with a SOURCES file per image folder. wger.de API page was blocked by an Anubis challenge (UNVERIFIED). FLAG: share-alike copyleft (data derivatives must be CC-BY-SA, attribution required) plus per-entry/per-image licences; AGPL if you embed wger code. Treat as reference only, or isolate and attribute properly.
- ExerciseDB (exercisedb/exercisedb-api): GitHub repo sidebar shows AGPL-3.0; advertises 5,000+ GIFs, 15,000+ videos, 20,000+ images. Page does not say whether media is covered by AGPL; its separate Terms of Use (exercisedb.notion.site) did not render the terms (UNVERIFIED). Treat media as NOT cleared for commercial redistribution until terms are read. AGPL also flags network-copyleft for code.
- Recommendation: do not ingest GIFs/images from any of these into a commercial app without a written rights check; use text data from free-exercise-db and commission/self-produce media.

## 4. Design-system patterns (opened)
- Material 3: m3.material.io/components/search/overview and /navigation-bar/guidelines - page is JavaScript-only; only meta text rendered (search shows suggested keywords as the user types; nav bar is a common handheld nav component). Detailed guidance UNVERIFIED.
- Apple HIG search fields (developer.apple.com/design/human-interface-guidelines/search-fields.md, page updated June 8 2026): (1) placeholder text states what is searchable; search as you type; show recents/suggestions. (2) Scope bar for clear categories, default to broad scope, tokens for common filters, pair tokens with suggestions. (3) Inline search above the list for filtering a single view; dedicated search tab when browsing+search go together.
- Apple HIG tab bars (.../tab-bars.md): (1) tabs for navigation only, not actions; keep bar visible; fewer tabs, avoid More overflow. (2) don't disable/hide a tab when empty - explain why. (3) single-word labels with icons; badge only for critical info. Convertible to sidebar on wider screens.
- Apple HIG charts (.../charts.md; the "charting-data" URL did not return text): (1) pick marks by purpose (bar compare/sums, line trend, point relation); fixed vs dynamic axis; zero baseline for bars. (2) title/summary states the main message; chart accessible with a label per important element; don't require interaction for critical info. (3) don't rely on colour alone (shapes/patterns), separate stacked segments.
- Carbon data table (carbondesignsystem.com/components/data-table/usage/): batch-action bar when rows selected (disable row actions meanwhile); toolbar for global actions, max five; five row heights 24-64 px with matching toolbar/pagination.
- Primer navigation (primer.style/product/ui-patterns/navigation/): parent/detail split with persistent sidebar; UnderlineNav if tab changes URL vs UnderlinePanels if it only switches panels, never mixed; on narrow screens sidebar becomes an index with back arrow or breadcrumbs.
- Fluent 2 data visualization (fluent2.microsoft.design/data-visualization): returned a 404 page - UNVERIFIED.

## 5. Product experiences (official pages only)
1. Trainerize (trainerize.com): quick program builder for workout, nutrition and habit plans assigned remote or in person; client app with messaging and badges/reactions for engagement.
2. TrueCoach (truecoach.co): write a program once and tweak per client; monthly calendar of past/upcoming sessions; dashboard of client status; 7/30/90-day compliance score (completed vs assigned).
3. TrainHeroic (trainheroic.com): one coach dashboard for remote and in-person athletes; athlete app plus plan marketplace. Calendar detail not shown (UNVERIFIED).
4. Hevy (hevyapp.com/features/): low-friction logging (start blank, prior values shown, auto rest timer, live PR alert); history becomes weekly sets per muscle, distribution chart, streak, measurements, photos.
5. Strava (support article on Fitness & Freshness): trend chart of Fitness/Fatigue/Form with adjustable range; tap a point for values; races marked. Feed/goals not verified (features page was marketing copy only).
6. Zocdoc (zocdoc.com): insurance-first filter; specialty chips; provider cards with rating, credentials, next-available date and direct Book button; curated lists such as shortest wait.
7. Practo (practo.com): city + specialty discovery; instant video consult vs in-clinic booking; no explicit filters seen on the page.
8. Mindbody (mindbodyonline.com/business): single shared calendar across booking channels; front-desk check-in, waivers attached to services, client profile + lead pipeline + automated follow-ups.
9. Shopify help (help.shopify.com/en/manual/fulfillment/managing-orders): order list search plus filters (fulfilment status, payment, date); payment vs fulfilment as two staged statuses; bulk actions not described.
10. Calendly (calendly.com/features): event types, availability with buffers and daily caps, calendar sync against double-booking, reminders/follow-up workflows, routing forms.
11. Notion tasks help (notion.com/help/tasks-and-dependencies): same task data across table/list/timeline/board/calendar; sub-task display and parent-only filtering differ by view; "My tasks" personal home referenced but not described.
- MyFitnessPal: pages did not yield usable detail (home fetch failed; help article was about export only) - UNVERIFIED.

## 6. Quick recommendations
- Safe permissive picks: Bootstrap Icons (exclude Brand set), ECharts (ship LICENSE+NOTICE+zrender BSD notice) or Chart.js (legend `rtl`), Motion core, AutoAnimate, FullCalendar standard plugins only.
- Avoid for a commercial product without purchase: FullCalendar premium plugins, ApexCharts (revenue-conditional), any wger/ExerciseDB media.
- Dev-only: axe-core (MPL), Playwright, Lighthouse - keep out of shipped bundle.
