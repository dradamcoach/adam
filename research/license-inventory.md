## General rules we should follow
1. A repo-wide licence does not automatically cover every asset inside it. Check README and sub-folders for third-party, brand, sample-image and font assets (examples above: Lucide's Feather subset, Tabler/Octicons brand icons, AdminLTE demo images, Material "no third-party logos").
2. Keep a `THIRD-PARTY-NOTICES.md` in the repo and ship it inside the web build and the Capacitor app (for example a "Licences" screen in Settings).
3. Pin exact versions; never load fonts, icons or CSS from a CDN at runtime without recording version + licence (self-host instead; this also helps privacy).
4. For every asset record: source URL, version/tag, date downloaded, licence text copy, and a SHA-256 checksum of the file you actually shipped.
5. Prefer permissive licences with a short, standard text (MIT, ISC, Apache-2.0, OFL-1.1). Treat custom licences (Remix Icon License v1.0) and paid tiers (CoreUI Pro) as "needs legal review" items.
6. Fonts under OFL: ship the OFL text with the font files; if you subset or convert, treat the result as a modified version and check the Reserved Font Name (IBM Plex reserves "Plex"; Cairo and Noto declare none).
7. Never use another company's logo, product icon or brand glyph as ADAM branding (Remix, GitHub, IBM, Apple clauses above).
8. Do not copy proprietary design-guideline text or imagery (Apple, Google M3, Microsoft Fluent): cite and link.
9. Re-check licences at every upgrade (AdminLTE says future releases may change licence; Remix changed in January 2026).
10. Store-submission note: Apple and Google do not review licences, but open-source notices are still a legal duty to the authors.
