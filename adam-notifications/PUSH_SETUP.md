# تأكيد الإيميل والإشعارات — خطوات التشغيل

التحديث ده فيه ٣ حاجات:

1. **تأكيد الإيميل** — أي حد جديد بيسجّل لازم يأكد إن الإيميل بتاعه قبل ما يكمّل. فايربيز بتبعت الرسالة بنفسها ومجانًا.
2. **الجرس** — أيقونة جرس فوق جنب زرار اللغة، عليها رقم باللي ما اتقراش. بتشتغل للعميل والمدرب وكل المتخصصين.
3. **إشعارات الموبايل** — نفس الإشعارات توصل على الموبايل حتى والبرنامج مقفول.

العملاء القدام اللي كملوا بياناتهم **مش هيتطلب منهم تأكيد** — محدش هيتقفل عليه.

---

## إيه اللي بيطلّع إشعار؟

| الحدث | مين بيوصله |
|---|---|
| رسالة في الشات من العميل | فريقه كله (مرة واحدة كل ٣ دقايق، مش مع كل رسالة) |
| رسالة في الشات من الفريق | العميل |
| حفظ برنامج التمرين / التغذية / التأهيل | العميل |
| طلب استشارة | المتخصص اللي العميل اختاره |
| الرد على استشارة | العميل |
| قرار الطبيب في الإذن الطبي | العميل + المدرب اللي طلب الإذن |
| بلاغ إصابة | فريق العميل كله |
| تغيير حالة بلاغ الإصابة | العميل |
| طلب حجز | المتخصص |
| تغيير حالة الحجز | العميل |
| عميل اختار متخصص في فريقه | المتخصص الجديد |

كل إشعار بيتكتب باللغتين، وبيوصل كل واحد بلغته هو. ولما تدوس عليه بيفتح المكان اللي يخصّه على طول.

## الخطوات بالترتيب

### ١ — ارفع ملفات GitHub
كل اللي في فولدر `github/`. بعدها تأكيد الإيميل يشتغل على طول.

### ٢ — انشر قواعد الأمان
Firebase Console ← **Firestore Database** ← **Rules** ← امسح اللي موجود والصق `firestore.rules` ← **Publish**.
من غير الخطوة دي الجرس هيفضل فاضي.

### ٣ — اتأكد إن دومين الموقع مسموح
Firebase Console ← **Authentication** ← **Settings** ← **Authorized domains**.
لازم يكون فيها `dradamcoach.github.io`. لو مش موجود دوس **Add domain** وضيفه.
(لو نسيته مش هيبوّظ حاجة — الرسالة هتتبعت برضه، بس من غير زرار "ارجع للموقع")

### ٤ — هات مفتاح الإشعارات
Firebase Console ← الترس ⚙ جنب Project Overview ← **Project settings** ← تبويب **Cloud Messaging**.
انزل لـ **Web configuration** ← **Web Push certificates** ← **Generate key pair**.
هيطلع مفتاح طويل بيبدأ بحرف B — انسخه.

المفتاح ده **عام ومش سر** — عادي يتحط في البرنامج.

### ٥ — حط المفتاح في لوحة التحكم
ادخل الموقع بحسابك ← لوحة التحكم ← **الرسالة الترحيبية التلقائية**.
هتلاقي خانة جديدة: الصق المفتاح فيها، وعلّم على **فعّل إشعارات الموبايل** ← **حفظ البيانات**.

### ٦ — اسمح لحساب الخدمة يبعت إشعارات
Google Cloud Console (نفس المكان اللي عملت منه حساب الخدمة للتقرير اليومي) ← **IAM & Admin** ← **IAM**.
دوّر على `adam-daily-report` ← القلم ✎ ← **Add another role** ← اختار **Firebase Cloud Messaging API Admin** ← **Save**.

وبعدين: **APIs & Services** ← **Library** ← دوّر على **Firebase Cloud Messaging API** ← لو مكتوب **Enable** دوس عليه.

### ٧ — حدّث Apps Script
افتح المشروع ← امسح الكود القديم ← الصق `daily-report.gs` ← **Save**.
اختار الدالة **testPushSetup** من فوق ← **Run** ← افتح **Execution log**:
- `تمام — الصلاحيات مظبوطة` ← كمّل
- `ناقص دور Firebase Cloud Messaging API Admin` ← ارجع للخطوة ٦

وبعدين **لازم**: **Deploy** ← **Manage deployments** ← القلم ✎ ← **Version: New version** ← **Deploy**.
من غير "New version" الرابط هيفضل شغال بالكود القديم ومش هيبعت إشعارات.

### ٨ — جرّب
- على موبايل أندرويد من Chrome: ادخل بحساب عميل ← دوس الجرس ← **فعّل الإشعارات** ← وافق.
- من حساب المدرب ابعت رسالة للعميل ده في الشات.
- المفروض الإشعار يوصل الموبايل حتى لو قفلت البرنامج.

## الآيفون

أبل مابتسمحش بإشعارات من المواقع غير لو الموقع **متضاف للشاشة الرئيسية** (iOS 16.4 أو أحدث).
البرنامج بيشرح ده للعميل بنفسه لما يفتح الجرس من سفاري:
زرار المشاركة ← **إضافة إلى الشاشة الرئيسية** ← يفتح ADAM من الأيقونة الجديدة ← يفعّل الإشعارات.

ملحوظة: أول مرة يفتح من الأيقونة هيحتاج يسجّل دخول تاني — ده طبيعي في الآيفون.

## لو حاجة ما اشتغلتش

| المشكلة | السبب الأغلب |
|---|---|
| عميل جديد بيأكد وبعدين بيطلعله خطأ صلاحيات وهو بيكمّل بياناته | ابعتلي صورة الرسالة فورًا |
| الجرس مابيطلعش أي حاجة | قواعد الأمان ما اتنشرتش (خطوة ٢) |
| زرار "فعّل الإشعارات" مش ظاهر | المفتاح أو علامة التفعيل ناقصين (خطوة ٥) |
| الجرس شغال بس الموبايل مابيرنّش | Apps Script: شوف **Executions** ← آخر `doPost` ← لو فيه `PUSH 403` يبقى خطوة ٦، لو مفيش سطور PUSH خالص يبقى ماعملتش New version في خطوة ٧ |
| رسالة التأكيد مش واصلة | الـ Spam. ولو مش هناك: Authentication ← Users ← اتأكد إن الإيميل مكتوب صح |

**مهم تعرفه:** قواعد الأمان الجديدة ماقدرتش أجرّبها هنا (أداة التجربة بتاعة فايربيز محجوبة في البيئة اللي بشتغل فيها). اتأكدت من كل الباقي بـ ٢٨ مجموعة اختبار، بس القواعد نفسها أول تجربة حقيقية ليها هتبقى عندك. أول ما تنشرها سجّل حساب تجريبي جديد وكمّل بياناته للآخر — لو عدّى يبقى كله تمام.
